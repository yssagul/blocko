How complex is Blocko compared to the world's most studied board games?

⚠ Deduplication: 5 Types, 32 Physical Blocks

Blocko has 32 physical blocks but only 5 distinct types (3×BB, 3×WW, 8×BW, 9×BR, 9×WR). The code's get_legal_moves() generates a separate move for each physical copy (e.g., BB₁ at corner ≠ BB₂ at corner), inflating the raw count by 6-8× in the opening.

All metrics below use deduplicated counts — moves that produce identical board states are collapsed. This means: same-type blocks are interchangeable, and flipping a uniform block (BB, WW) is a no-op. The reduction decreases through the game (from 8× at ply 1 to 1.2× at ply 32) as duplicates get used up.

Could Blocko Be Solved?

Solvability Frontier

Where Blocko Sits

State-space (~10²⁰) is comparable to Checkers (10²¹), which was weakly solved in 2007 after 18 years of computation. This puts Blocko in the "theoretically approachable" zone for state-space enumeration.
Game tree (~10⁵⁷) is comparable to Othello (10⁵⁸). Othello was claimed weakly solved in 2023 — still under verification. This suggests Blocko's game tree is at the frontier of solvability.
High branching factor (~109) makes alpha-beta pruning less effective than in games like Checkers (b≈8) or Chess (b≈35). Each search level requires evaluating ~100+ distinct moves.
Verdict: Blocko is not easily solvable with current technology. A weak solution might be feasible with significant computational investment (years of dedicated research), but a strong solution (complete strategy database) is impractical given ~10²⁰ positions to store.

Key Differences

Opening phase: Open Grid has 2.7× more opening moves (864 vs 320 effective) because the floating grid allows blocks to be placed at any initial position.
Mid/late game convergence: By ply 8, both variants have nearly identical branching (~160 effective), since the grid has locked into a 4×4 footprint.
State-space identical: Once the board is full, both variants produce the same set of possible configurations (modulo coordinate translation).
Game tree ~10× larger: Open Grid's tree is 10^1.5 ≈ 30× larger than Standard, driven entirely by the extra opening flexibility.

Analysis computed via empirical simulation (200 games/variant) and column-based DP over the 4×4×4 grid. Reference data from Allis (1994), Herik et al. (2002), Schaeffer et al. (2007).
